The `respond_to?` method is used to check if an object can respond to a given method. It returns `true` if the object has a method with the specified name, either as an instance method or a private method, depending on the options provided.

### Syntax

```ruby
object.respond_to?(:method_name)
```

- `object`: The object you want to check.
- `:method_name`: The symbol representing the method name you want to check for.

### Options

You can pass additional options to `respond_to?`:

- `include_all`: If set to `true`, it checks for private and protected methods as well. By default, it only checks for public methods.

```ruby
object.respond_to?(:method_name, true)
```
